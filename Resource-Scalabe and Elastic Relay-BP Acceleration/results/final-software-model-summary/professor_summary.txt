We studied the circuit-level decoding graph for the Gross [[144,12,12]] memory-Z experiment, containing 1,728 checks and 67,752 fault variables. METIS showed that the graph has strong partitionable locality, reducing the balanced edge-cut ratio to about 10.45%. However, METIS reordering alone did not improve folding because the P=4 memory conflicts depend on address modulo four rather than generic graph locality. BA2 instead placed faults and messages into banks using the access groups that the folded decoder actually requests together. In the software model, BA2 removed variable-phase MU/NU retries, reduced total structural retries by 57.6%, and reduced trajectory-weighted modeled cycles by about 15% relative to the original layout. All 256 archived E0/E1 Relay-BP trajectories and all 47,736 mapped iterations remained exact, so the decoder behavior did not change. The remaining work is to validate BA2 on other graphs and folding factors before considering any hardware implementation or speedup claim.
