The selected layout is **BA2**. This folder consolidates the validated graph, METIS, P=4 folding, BA2 equivalence, refinement-decision, and optional stagnation-priority results without rerunning the decoder or introducing a new layout.

Start with `final_report.md`. Machine-readable headline values are in `key_metrics.json`; the main and optional comparisons are in `final_comparison.csv` and `optional_stagnation_comparison.csv`. `research_pipeline.txt`, `limitations.md`, and `professor_summary.txt` provide focused views for architecture discussion.
